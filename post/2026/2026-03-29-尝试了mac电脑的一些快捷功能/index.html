2026 03 29 尝试了Mac电脑的一些快捷功能

2026-03-29
个人笔记
约 232 字 预计阅读 1 分钟

文章目录

用了Mac电脑10来年了。有些功能，我还真是没怎么用过。

  • 尝试了听写功能，设定了快捷键 option +D 开启了Mac电脑的语音输入转文字的功能。在不想打字的时候，只要用口头表述，这种语音转文字输入方式也可以可行的。

  • 同一个应用内部 用 command + ` 来快速切换

  • 分屏功能，在Safari 或者Chrome点击 绿色图标， 长按，可以选择开双屏，或者多屏。

  • 用 command + space 来打开Mac上的所有应用， 或搜索

  • 用command + shift + 5 来录制屏幕

我已经会的功能：

  • command + Tab 来切换任务窗口

  • command + W 来关闭任务窗口

  • command + shift +3 截图为文件
